# PRD：SolidWorks MCP Server

**版本**: 1.0  
**日期**: 2026-07-17  
**关联项目**: E:\SolidWorks 2026\SolidWorksMCP  
**档位**: 🔴 L3（需求范围大、影响半径大、需完整设计与任务规划）

---

## 1. 背景与目标

### 1.1 背景

用户希望通过 AI 自动完成各类 SolidWorks 设计任务。当前已有一种基础验证方式（VBA 宏），但需要用户手动在 SolidWorks 中复制粘贴运行，无法做到自然语言驱动。

### 1.2 目标

构建一个 **SolidWorks MCP Server**，使 Claude Code 能够通过 MCP 协议调用 SolidWorks 2026 API，实现自然语言控制 SolidWorks 完成设计任务。

### 1.3 真实任务（JTBD）

- 当用户想快速生成一个标准几何体时，希望用一句话让 SolidWorks 自动建模，而不必手动点击菜单。
- 当用户需要批量处理文件（导入、导出、测量）时，希望 AI 能自动调用 SolidWorks API 完成。
- 当用户不熟悉 SolidWorks API 时，希望用自然语言描述需求，由 AI 自动翻译成 API 调用。

### 1.4 反目标

- 不替代 SolidWorks 的专业设计判断（复杂设计仍由人类主导）。
- 不绕过用户确认执行破坏性操作（保存/覆盖/删除必须确认）。
- 不追求一次性覆盖 100% 的 SolidWorks API（先 MVP，再迭代扩展）。

## 2. 用户角色与交互模式

### 2.1 用户角色

| 角色 | 描述 | 使用场景 |
|------|------|---------|
| **SolidWorks 操作者** | 对 SolidWorks 不熟悉，希望用自然语言完成基础操作 | "帮我创建一个直径 50mm、高 100mm 的圆柱" |
| **自动化测试/批量处理人员** | 需要重复执行导入、导出、测量等任务 | "批量导入 SampleSTEPs 文件夹里的 STEP 文件并检查体积" |
| **设计辅助人员** | 熟悉设计但希望加快建模流程 | "在这个零件上开 4 个 M6 的孔" |

### 2.2 交互模式

1. 用户在 Claude Code 中输入自然语言指令。
2. Claude Code 解析意图，选择合适的 MCP 工具。
3. MCP Server 接收工具调用，转换为 SolidWorks COM API 调用。
4. SolidWorks 执行操作并返回结果。
5. Claude Code 汇总结果并反馈给用户。

## 3. 功能需求（FR）

### FR-001：SolidWorks 连接管理
- **描述**: MCP Server 启动时，尝试连接已运行的 SolidWorks 2026 实例；若未运行，提示用户手动启动。
- **验收标准 (AC)**:
  - AC-001.1: 能检测到已运行的 SolidWorks 进程并连接。
  - AC-001.2: SolidWorks 未运行时返回清晰的错误提示。
  - AC-001.3: 支持获取 SolidWorks 版本号。

### FR-002：基础零件建模
- **描述**: 支持通过自然语言创建常见几何体（圆柱、立方体、圆锥、球体、五角星等）。
- **验收标准 (AC)**:
  - AC-002.1: 能创建指定尺寸的圆柱体。
  - AC-002.2: 能创建指定边长的立方体。
  - AC-002.3: 能创建草图并进行拉伸/旋转/切除操作。
  - AC-002.4: 操作失败时返回具体错误信息。

### FR-003：文件导入导出
- **描述**: 支持打开、保存、导入 STEP/IGES/STL/SLDPRT 等格式文件。
- **验收标准 (AC)**:
  - AC-003.1: 能打开指定路径的 SLDPRT/SLDASM 文件。
  - AC-003.2: 能导入 STEP/IGES/STL 文件。
  - AC-003.3: 能导出当前文档为 STEP/STL/SLDPRT。
  - AC-003.4: 覆盖已有文件前必须获得用户确认。

### FR-004：装配体操作
- **描述**: 支持在装配体中插入零部件、添加基础配合关系。
- **验收标准 (AC)**:
  - AC-004.1: 能向装配体中插入已有零件文件。
  - AC-004.2: 能添加重合、同心、距离等基础配合。
  - AC-004.3: 能获取装配体中的零部件清单。

### FR-005：工程图出图
- **描述**: 支持为零件或装配体创建基础工程图。
- **验收标准 (AC)**:
  - AC-005.1: 能创建新工程图文档。
  - AC-005.2: 能插入标准三视图。
  - AC-005.3: 能添加基础尺寸标注。

### FR-006：查询与验证
- **描述**: 支持读取模型属性、测量尺寸、检查几何。
- **验收标准 (AC)**:
  - AC-006.1: 能读取质量属性（体积、表面积、质量、重心）。
  - AC-006.2: 能测量两点/两面之间的距离。
  - AC-006.3: 能获取特征树清单。

### FR-007：特征树批量操作
- **描述**: 支持遍历、重命名、抑制/解除抑制特征。
- **验收标准 (AC)**:
  - AC-007.1: 能列出所有特征名称。
  - AC-007.2: 能按名称重命名特征。
  - AC-007.3: 能抑制或解除抑制指定特征。

### FR-008：安全与确认机制
- **描述**: 所有可能影响用户数据的操作都需要显式确认。
- **验收标准 (AC)**:
  - AC-008.1: 保存到新路径无需确认。
  - AC-008.2: 覆盖已有文件必须确认。
  - AC-008.3: 删除文件或特征必须确认。
  - AC-008.4: MCP Server 本身不主动执行任何写文件操作，除非通过工具调用。

## 4. 约束与假设

### 4.1 技术约束

- 运行环境：Windows 10/11 + SolidWorks 2026。
- Python 版本：3.9+（当前环境为 3.9.13）。
- 必须安装 `pywin32` 以调用 SolidWorks COM API。
- Claude Code 必须配置 MCP server（通过 `.claude/settings.json` 或项目级配置）。

### 4.2 业务约束

- 用户必须拥有 SolidWorks 2026 正版授权。
- 用户需要手动启动 SolidWorks（优先选择简单稳定方案，暂不支持自动启动）。
- 复杂设计决策仍由人类完成，AI 只执行明确、可自动化的操作。

### 4.3 假设

- 用户已安装 SolidWorks 2026 并能正常运行。
- 用户愿意在本地运行一个 Python MCP server。
- 用户的 SolidWorks 语言版本为中文或英文（模板路径需兼容两种语言）。

## 5. 成功指标

### 5.1 定性指标

- 用户能使用自然语言完成至少 5 种常见 SolidWorks 操作。
- 错误提示清晰，非专家能看懂。
- 所有破坏性操作都有确认机制。

### 5.2 定量指标

- 每个 FR 至少 80% 的 AC 通过测试。
- MCP Server 启动后能在 5 秒内连接 SolidWorks。
- 基础建模指令（圆柱/立方体）端到端延迟 < 10 秒。

## 6. 风险与依赖

### 6.1 风险

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| SolidWorks API 调用失败 | 高 | 每个工具调用加 try/except，返回详细错误 |
| 模板路径因语言/安装位置不同 | 中 | 动态搜索常见模板路径 |
| 并发调用导致 SolidWorks 不稳定 | 中 | 工具调用串行化，避免并发 |
| 用户误操作导致数据丢失 | 高 | 严格确认模式，覆盖/删除必须确认 |
| pywin32 与 Python 版本不兼容 | 中 | 使用与 Python 版本匹配的 pywin32 |

### 6.2 外部依赖

- `pywin32` 库
- `mcp` Python SDK（`modelcontextprotocol/python-sdk` 或 `fastmcp`）
- SolidWorks 2026 Type Library

---

## 7. Out of Scope

以下功能不在第一期范围内：

- 自动启动 SolidWorks（优先手动启动保证稳定性）。
- 复杂曲面建模（放样、扫掠、边界曲面等）。
- 高级仿真分析（Simulation、Flow Simulation）。
- PDM 集成。
- 多用户并发控制。
- 完全替代人类设计师的创造性决策。

---

## 8. 实现思路摘要

1. 安装 `pywin32` 和 `mcp` SDK。
2. 创建 Python 包 `solidworks_mcp`，封装 SolidWorks COM API 调用。
3. 创建 `server.py`，基于 MCP SDK 暴露工具（tools）。
4. 每个工具对应一个 SolidWorks 操作，统一错误处理和确认机制。
5. 配置 Claude Code 的 MCP 设置。
6. 编写单元测试和集成测试验证核心功能。

## 1. 北极星与终态画面

**北极星一句话**：把「一段工程需求」自动变成「一套可直接下发制造的交付包」——无人值守、自检闭环、全程可审计。

**终态用户故事（产品验收的最高叙事）**：

> 机械工程师晚上 20:00 把 20 个法兰变体的需求表（自然语言+参数）丢进 aicad 队列，早上 08:00 收到 20 个交付包。每个包含：参数化 .sldprt（特征树可编辑回溯）、STEP/STL 中性格式、制造级工程图（PDF/DXF：三视图+尺寸+公差+BOM 表+爆炸图）。合格率 ≥95%，失败的那几个带着失败归因报告（哪一步、什么原因、差多少）。

这继承了项目愿景（「AI 无人值守全自动出 3D 机械图」）并把它从「能力」升格为「产品」：**能力是工具箱，产品是工厂**。

## 3. 最终形态：六层模型

```
┌─────────────────────────────────────────────────────────────┐
│ L6 产品化层  一键安装 / 许可激活 / 文档示例库 / 多机部署        │ ← 最大缺口
├─────────────────────────────────────────────────────────────┤
│ L5 质量层    评测集 50+ 任务 / 夜间自动迭代 / 观测报表 / 溯源    │ ◐ 19 任务已有
├─────────────────────────────────────────────────────────────┤
│ L4 引擎层    SW 原生(参数化交付) ⇄ build123d 沙箱(免费预演)    │ ✅ 双引擎+CSG 互证
│             双向互证（契约 v3 目标：导出方向补全）              │ v2 仅重建方向
├─────────────────────────────────────────────────────────────┤
│ L3 能力层    零件全覆盖 / 装配约束求解 / 图纸 GD&T / CSG v3     │ ◐ 五族 BLOCKED
├─────────────────────────────────────────────────────────────┤
│ L2 自治层    plan-then-execute / RAG / mate 求解器 / 模型路由  │ ◐ S5 一期落地
│             / 自检修复闭环 / 失败归因报告                       │ 归因批收口中
├─────────────────────────────────────────────────────────────┤
│ L1 体验层    对话+3D 预览（已有）/ 批量队列+交付包下载（待建）    │ ◐ 队列是终态门面
└─────────────────────────────────────────────────────────────┘
```

**终态的三个不可妥协属性**（产品原则，优先级冲突时的裁决依据）：

1. **可审计**：每个交付包可回溯到特征树级操作序列（AI 干了什么、为什么）——区别于黑盒生成的护城河。现状 ✅（特征树+评测断言+探针留档文化）。
2. **可制造**：输出即制造级（国标图纸模板/公差/BOM/材料），不是「看起来像」的演示件。现状 ✅（gb_a 模板+公差/粗糙度已落地）。
3. **无人值守下诚实失败**：失败必须带归因报告返回，绝不静默吞错或硬凑结果。现状 ✅ 文化已立（PTE 诚实回退、S5 归因批、BLOCKED 如实声明）——这是全项目最珍贵的资产，产品化过程中**不可稀释**。

## 5. 路线图（映射 N 系列惯例）

> 节奏沿用「每晚 1-2 任务、评测护栏、审查驱动立项」的既有节奏；不另起流程。

**第七期（候选：自治收口 + 终态门面）**——建议 4 个 P0 全部在此期：
1. **N42** eval 基建修复（复跑死亡归因——OpenBLAS 内存分配已定谳，收尾）+ 同 provider 复测（GLM key 恢复后）→ 剥离 provider 变量的真实 S5 贡献。
2. **N43** S5 v2 裁决（守门条款：归因数据齐后立项——script 件 STEP 拼装 / embedding 检索 / solver 扩原语，按数据定范围）。
3. **N44** 批量队列 + 交付包打包（G3）：队列 API（需求表→逐任务跑→聚合）+ 交付包 zip 结构定义 + 失败归因报告格式。终态门面落地。
4. **N45** 评测集扩容至 30+（G2 第一波）：补 GD&T/BLOCKED 域/编辑型任务。

**第八期（能力完备波）**：G4 宏录制器解锁五族（需用户配合录制宏，一次性投入）、G5 GD&T、N45 续（50 任务）、G6 CSG v3。
> **路线图勘误（2026-09-10 立第十期时注）**：本节所述「第八期/第九期」为 v1.0 时点的编号预期；实际第八期=S5 v2 自治韧性（N46/N47）、第九期=产品化波（N48-N51）。**「能力完备波」内容整体顺延为第十期**（`output/optimization-plan-2026-09-10-3.md`）。

**第九期（产品化波）**：G9 打包/安装/文档/示例库、G8 路由策略、（视需求）G10 多机。

**远期观察（不承诺）**：RAG embedding 升级、通用 mate CSP、Mac/Linux（受 COM 约束基本无解，除非 SW 云 API 或纯 OCCT 路线——build123d 引擎独立产品化是另一条产品线决策，见 §7 D3）。

## 6. 度量体系

**北极星指标**：`无人值守交付包合格率`（评测集通过率）——目标 95%（**当前 46/50 = 92%（2026-09-12 终态：42/50+歧义修复 3+U10 窗口 1）**；伪影持续为零，4 败全=装配堆叠解释（plan 强档域，N59 路由后复跑）——差距分解见 `aicad/docs/s5-net-contribution-report.md` §8.3-§8.5。口径链随尺子加宽不可跨比：57.9%(19)→84.2%(19)→90%(30)→92%(50 终态)）。

**护栏指标**（不可为北极星牺牲）：
- 诚实失败率 = 失败任务中带归因报告的比例（目标 100%，现状已达成——保持）
- 首轮通过率 first_pass（v2 后 25/30=83% first_pass、avg 1.17 轮——自治层别为凑过率多烧轮次）
- 主仓覆盖率 ≥89% / 工具计数锁 / 双 CI 绿（工程护栏全继承）
- 成本/任务（多模型路由后进报表——G8 产物）

**反指标（警惕）**：为通过率造简单靶任务（S5 反目标已立）；静默重试掩盖问题；用 mock 冒充 live。

## 7. 决策点（需产品负责人裁决）

| ID | 决策 | 推荐 | 影响 |
|---|---|---|---|
| D1 | 第七期范围：4 个 P0 是否全包 | 全包（G1-G3 是北极星直达路径） | 锁定 1-2 周 |
| D2 | GLM key 恢复后是否复测（花用户钱） | 复测一次（剥离 provider 变量是 S5 v2 裁决前置） | 一次 live 全量 ≈ 19 任务 |
| D3 | build123d 引擎是否独立产品线（无 SW 免费版） | **暂不**——作为双引擎互证件+超长期观察（纯 OCCT 路线与「可制造+SW 特征树」原则冲突） | 避免战线分散 |
| D4 | 宏录制器解锁（G4）用户投入意愿 | 第八期排入，需用户每个 BLOCKED 族手工录宏一次（约 30min/族） | 参数化 100% 的唯一已知路径 |
| D5 | 安装包形态（frozen exe vs 容器 vs 源码+脚本） | **已裁决（2026-09-10，N49 依 N48 实测）**：**frozen onedir 为分发包主形态**（16s 构建/47MB/0.6s 握手/79 工具保真，pywin32 零配置——`docs/packaging-frozen-report.md`）；源码+venv 为开发者形态保留；容器否决（目标用户=Windows+SW 桌面工位，COM 无容器路径） | 产品分发模式 |

## 8. 非目标（终态明确不做的）

- ❌ 通用 CAD 内核替代（不自研几何内核；SW+OCCT 双引擎即边界）
- ❌ 云端 SaaS 多租户（单机/局域网产品形态；云化在 G10 之后另议）
- ❌ CAM/加工仿真（交付到「可下发制造的图纸包」为止）
- ❌ 为通过率优化而优化（95% 是北极星，100% 不是——诚实失败比虚假满分更符合产品原则 3）
